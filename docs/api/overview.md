# API v1 overview

All current first-party endpoints are rooted at `/api/v1/`. Breaking changes require a new version; additive fields are non-breaking. Use JSON, HTTPS, and server-side business validation.

Current resources: catalog products/categories, cart, checkout/orders, payments/webhooks, supplier wallet/payouts, notifications, and superadmin monitoring. Internal ledger/audit mutation endpoints are intentionally absent.

# BUILTASUPPLY design system

Deep navy is for navigation, green for confirmed states, amber for pending states, red for failure, and blue for information. All statuses include labels, not color alone. Use an 8/12/16/24/32px spacing scale, labeled fields, solid buttons, bordered surfaces, compact tables, and visible keyboard focus. Navigation wraps on small screens; product grids use a 220px minimum card width; dense tables should preserve priority columns on tablet/mobile.
